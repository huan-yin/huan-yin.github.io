位置编码详解

位置编码（Position Encoding）详解

本文系统讲解 Transformer 中三类经典位置编码：正余弦位置编码（Sinusoidal PE）、
旋转位置编码（RoPE，实数 / 复数两种实现） 与 三维旋转位置编码（3D RoPE）。
每种编码都从「为什么 → 数学公式 → 完整 PyTorch 代码 → 可视化验证」四个角度展开。

0. 为什么需要位置编码？

自注意力（Self-Attention）的核心计算是：

Attention(Q,K,V)=softmax ⁣(QK⊤d)V\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d}}\right)V Attention(Q,K,V)=softmax(d​QK⊤​)V

它对输入序列是置换不变（permutation-invariant）的：把输入 token 的顺序任意打乱，
注意力输出也只是同样地被打乱，模型本身完全感知不到"谁在前谁在后"。
但语言、图像、视频都有强烈的顺序/空间结构，因此必须显式注入位置信息，这就是位置编码。

常见路线有两大家族：

路线 做法 代表
加法式（绝对位置） 给每个位置生成一个向量，加到嵌入上 正余弦 PE（原始 Transformer）
乘法式（相对位置） 用位置对 q/k 做旋转，让内积只依赖相对距离 RoPE（LLaMA、Qwen）→ 3D RoPE（CogVideoX、HunyuanVideo）

下面逐一讲解。

1. 正余弦位置编码（Sinusoidal Position Encoding）

出自《Attention Is All You Need》(Vaswani et al., 2017)，是原始 Transformer 的绝对位置编码。

1.1 数学公式

对位置 pos（0, 1, 2, …）和维度下标 i（0 ~ d_model/2），定义：

PE(pos, 2i)=sin⁡ ⁣(pos100002i/dmodel),PE(pos, 2i+1)=cos⁡ ⁣(pos100002i/dmodel)PE(pos,\ 2i) = \sin\!\left(\frac{pos}{10000^{2i/d_{model}}}\right), \qquad PE(pos,\ 2i+1) = \cos\!\left(\frac{pos}{10000^{2i/d_{model}}}\right) PE(pos, 2i)=sin(100002i/dmodel​pos​),PE(pos, 2i+1)=cos(100002i/dmodel​pos​)

  • 偶数维填 sin，奇数维填 cos，正好各占一半；
  • 第 iii 对维度对应的波长为 2π⋅100002i/dmodel2\pi \cdot 10000^{2i/d_{model}}2π⋅100002i/dmodel​：
    低维（i 小）波长短、变化快，捕捉局部位置；高维（i 大）波长可达上万，捕捉全局位置；
  • 使用方式极简单——直接加到词嵌入上：x=token_embedding+PEx = \text{token\_embedding} + PEx=token_embedding+PE。

相对位置性质：对任意固定偏移 kkk，PE(pos+k)PE(pos+k)PE(pos+k) 是 PE(pos)PE(pos)PE(pos) 的线性函数。
证明只需看一对维度，记 ωi=10000−2i/dmodel\omega_i = 10000^{-2i/d_{model}}ωi​=10000−2i/dmodel​，由三角恒等式：

(sin⁡((pos+k)ωi)cos⁡((pos+k)ωi))=(cos⁡(kωi)sin⁡(kωi)−sin⁡(kωi)cos⁡(kωi))⏟只依赖 k 的线性变换(sin⁡(pos ωi)cos⁡(pos ωi))\begin{pmatrix} \sin((pos{+}k)\omega_i) \\ \cos((pos{+}k)\omega_i) \end{pmatrix} = \underbrace{\begin{pmatrix} \cos(k\omega_i) & \sin(k\omega_i) \\ -\sin(k\omega_i) & \cos(k\omega_i) \end{pmatrix}}_{\text{只依赖 } k \text{ 的线性变换}} \begin{pmatrix} \sin(pos\,\omega_i) \\ \cos(pos\,\omega_i) \end{pmatrix} (sin((pos+k)ωi​)cos((pos+k)ωi​)​)=只依赖 k 的线性变换(cos(kωi​)−sin(kωi​)​sin(kωi​)cos(kωi​)​)​​(sin(posωi​)cos(posωi​)​)

即模型容易从这种编码中学出"相对距离"信息。这个"二维子空间里的旋转"正是后面 RoPE 的灵感来源。

2. 旋转位置编码 RoPE（实数 rotate_half 实现）

出自《RoFormer: Enhanced Transformer with Rotary Position Embedding》(Su et al., 2021)，
被 LLaMA、Qwen、GPT-NeoX 等主流大模型采用，也是视频生成模型中 3D RoPE 的基础。

2.1 数学公式

核心思想：不再把位置向量加到嵌入上，而是把 d 维向量两两分组
(x0,x1),(x2,x3),…(x_0,x_1), (x_2,x_3), \dots(x0​,x1​),(x2​,x3​),…，每组看作一个二维向量，对位置 mmm 处的向量，
第 iii 组按角度 mθim\theta_imθi​ 做旋转：

(x2i′x2i+1′)=(cos⁡mθi−sin⁡mθisin⁡mθicos⁡mθi)⏟Ri(m)(x2ix2i+1),θi=10000−2i/d\begin{pmatrix} x'_{2i} \\ x'_{2i+1} \end{pmatrix} = \underbrace{\begin{pmatrix} \cos m\theta_i & -\sin m\theta_i \\ \sin m\theta_i & \cos m\theta_i \end{pmatrix}}_{R_i(m)} \begin{pmatrix} x_{2i} \\ x_{2i+1} \end{pmatrix}, \qquad \theta_i = 10000^{-2i/d} (x2i′​x2i+1′​​)=Ri​(m)(cosmθi​sinmθi​​−sinmθi​cosmθi​​)​​(x2i​x2i+1​​),θi​=10000−2i/d

注意 θi\theta_iθi​ 与正余弦编码用的是同一组频率。整个 d 维旋转矩阵
R(m)R(m)R(m) 是由 d/2d/2d/2 个 Ri(m)R_i(m)Ri​(m) 组成的块对角矩阵。

相对位置性质（RoPE 的灵魂）：利用旋转矩阵的性质 R(m)⊤R(n)=R(n−m)R(m)^\top R(n) = R(n-m)R(m)⊤R(n)=R(n−m)，
对 query（位置 m）和 key（位置 n）同时旋转后：

⟨RoPE(q,m), RoPE(k,n)⟩=(R(m)q)⊤(R(n)k)=q⊤R(m)⊤R(n) k=q⊤R(n−m) k\langle \text{RoPE}(q,m),\ \text{RoPE}(k,n) \rangle = (R(m)q)^\top (R(n)k) = q^\top R(m)^\top R(n)\, k = q^\top R(n-m)\, k ⟨RoPE(q,m), RoPE(k,n)⟩=(R(m)q)⊤(R(n)k)=q⊤R(m)⊤R(n)k=q⊤R(n−m)k

内积只依赖相对位置 m−nm-nm−n！注意力分数 QK⊤QK^\topQK⊤ 天然携带相对位置信息，
无需任何额外参数——这正是 RoPE 被现代 LLM 广泛采用的根本原因。

实现要点：实际代码不会显式构造稀疏的块对角旋转矩阵，而是展开逐元素恒等式：

x2i′=x2icos⁡mθi−x2i+1sin⁡mθi,x2i+1′=x2isin⁡mθi+x2i+1cos⁡mθix'_{2i} = x_{2i}\cos m\theta_i - x_{2i+1}\sin m\theta_i,\qquad x'_{2i+1} = x_{2i}\sin m\theta_i + x_{2i+1}\cos m\theta_i x2i′​=x2i​cosmθi​−x2i+1​sinmθi​,x2i+1′​=x2i​sinmθi​+x2i+1​cosmθi​

写成向量形式（即 rotate_half 技巧）：

x′=x⊙cos⁡+rotate_half(x)⊙sin⁡,rotate_half([a,b])=[−b,a] (对每个二维分组)x' = x \odot \cos + \text{rotate\_half}(x) \odot \sin, \qquad \text{rotate\_half}([a, b]) = [-b, a]\ (\text{对每个二维分组}) x′=x⊙cos+rotate_half(x)⊙sin,rotate_half([a,b])=[−b,a] (对每个二维分组)

两种配对约定：维度如何两两配对有两种等价惯例——

  1. 交错配对（GPT-J 风格，pairing="interleaved"）：相邻两维一组 (x0,x1),(x2,x3),…(x_0,x_1),(x_2,x_3),\dots(x0​,x1​),(x2​,x3​),…；
  2. 对半分配对（GPT-NeoX / LLaMA 风格，pairing="half"，默认）：前半段与后半段一一配对
    (xi,xi+d/2)(x_i, x_{i+d/2})(xi​,xi+d/2​)，此时 rotate_half([x1,x2])=[−x2,x1]\text{rotate\_half}([x_1, x_2]) = [-x_2, x_1]rotate_half([x1​,x2​])=[−x2​,x1​]。

两者数学上完全等价（旋转后内积都只依赖相对位置），只是维度排列不同，
实际模型按其权重布局选用其一，迁移权重时必须对齐约定。

3. RoPE 的复数实现（LLaMA 官方风格）

3.1 数学公式

二维平面上的旋转恰好就是复数乘法。把每个二维分组看成一个复数
zi=x2i+i x2i+1z_i = x_{2i} + \mathrm{i}\,x_{2i+1}zi​=x2i​+ix2i+1​，则"旋转角度 mθim\theta_imθi​"等价于乘以单位复数
eimθie^{\mathrm{i} m\theta_i}eimθi​：

zi′=zi⋅eimθiz'_i = z_i \cdot e^{\mathrm{i} m\theta_i} zi′​=zi​⋅eimθi​

用欧拉公式 eiφ=cos⁡φ+isin⁡φe^{\mathrm{i}\varphi} = \cos\varphi + \mathrm{i}\sin\varphieiφ=cosφ+isinφ 展开，
得到的正是第 2 节的实数恒等式，两种写法逐元素等价。

相对位置性质在复数语言下更加一目了然：

⟨RoPE(q,m), RoPE(k,n)⟩=Re ⁣[ q⋅k‾⋅ei(m−n)θ ]\langle \text{RoPE}(q,m),\ \text{RoPE}(k,n) \rangle = \text{Re}\!\left[\, q \cdot \overline{k} \cdot e^{\mathrm{i}(m-n)\theta} \,\right] ⟨RoPE(q,m), RoPE(k,n)⟩=Re[q⋅k⋅ei(m−n)θ]

共轭相乘使角度相减，内积只依赖 m−nm-nm−n。

4. 三维旋转位置编码（3D RoPE）

4.1 数学公式

1D RoPE 处理的是标量位置 mmm；而视频 / 3D 体素数据中每个 token 的位置是三元组
p=(t,h,w)p = (t, h, w)p=(t,h,w)（时间帧、空间行、空间列）。CogVideoX、HunyuanVideo 等视频生成模型
使用的正是 3D RoPE。

核心思想：分轴旋转。把 head_dim 切成三段 (dt,dh,dw)(d_t, d_h, d_w)(dt​,dh​,dw​)，每段独立做普通 RoPE，
各自只编码一个坐标轴：

  • 前 dtd_tdt​ 维：只用 ttt 坐标的角度旋转；
  • 中 dhd_hdh​ 维：只用 hhh 坐标的角度旋转；
  • 后 dwd_wdw​ 维：只用 www 坐标的角度旋转。

每段内部采用交错配对：相邻两维 (x0,x1),(x2,x3),…(x_0,x_1), (x_2,x_3), \dots(x0​,x1​),(x2​,x3​),… 构成二维分组，
按角度 paxis⋅θip_{\text{axis}} \cdot \theta_ipaxis​⋅θi​ 旋转，θi=base−2i/daxis\theta_i = \text{base}^{-2i/d_{\text{axis}}}θi​=base−2i/daxis​。

相对位置性质：由于旋转按轴分块、逐块正交，query 与 key 的内积分解为三段之和：

⟨RoPE(q,p), RoPE(k,p′)⟩=∑axis∈{t,h,w}qaxis⊤R(Δaxis) kaxis,Δ=p−p′\langle \text{RoPE}(q, p),\ \text{RoPE}(k, p') \rangle = \sum_{\text{axis} \in \{t,h,w\}} q_{\text{axis}}^\top R(\Delta_{\text{axis}})\, k_{\text{axis}}, \qquad \Delta = p - p' ⟨RoPE(q,p), RoPE(k,p′)⟩=axis∈{t,h,w}∑​qaxis⊤​R(Δaxis​)kaxis​,Δ=p−p′

内积只依赖三维相对位移 Δ=(Δt,Δh,Δw)\Delta = (\Delta t, \Delta h, \Delta w)Δ=(Δt,Δh,Δw)，
与绝对位置无关——1D RoPE 的优良性质在 3D 下完整保留。

5. 正余弦位置编码 vs 旋转位置编码：优劣势分析

前面几节分别给出了两种编码的原理与实现，这一节从工程与理论两个角度系统对比它们的优劣。

5.1 正余弦位置编码的优势

  1. 零参数、零训练成本：编码完全由公式确定，没有任何需要学习的参数，
    不会引入额外的优化负担或过拟合风险。
  2. 实现极简、即插即用：一次预计算后只是一个加法，完全不侵入注意力结构，
    任何 Transformer 变体都可以无改造接入。
  3. 位置信息全网络可见：编码加在输入嵌入上，随后每一层的 FFN、残差连接、
    归一化都能直接"看到"位置信号，不限于注意力路径。
  4. 行为完全可解释：每个维度就是一条已知频率的 sin/cos 曲线，
    编码的几何结构（多频率、相对位置的线性可表性）有严格的数学刻画，便于分析与调试。

5.2 正余弦位置编码的劣势

  1. 位置信号随深度被稀释：位置只在输入层注入一次，经过多层线性变换与
    非线性混合后，深层表示中的位置信息越来越弱——模型越深，这个问题越明显。
  2. 相对位置是间接的：PE(pos+k)PE(pos+k)PE(pos+k) 虽是 PE(pos)PE(pos)PE(pos) 的线性函数，但模型必须
    自己学出这个线性变换才能利用相对距离；注意力分数本身并不显式包含
    相对位置，学习效率和归纳偏置都弱于 RoPE。
  3. 长度外推能力名不副实：虽然对任意 pos 编码都有定义，看似可以外推，
    但 ALiBi 论文（Press et al., 2022）的实验表明：超出训练长度后，
    未见过的 sin/cos 值组合会让注意力分布失真，困惑度迅速恶化——
    “能算出编码"不等于"模型认识这个编码”。
  4. 位置与内容纠缠在同一表示中：加法注入让位置向量与语义向量占用同一组
    维度、互相干扰；为了容纳位置信号，嵌入必须让出一部分容量。
  5. 注意力分数中的位置贡献不可控：(xe+pq)⊤(xe+pk)(x_e + p_q)^\top(x_e + p_k)(xe​+pq​)⊤(xe​+pk​) 展开后
    同时含有"内容×内容"“内容×位置”"位置×位置"四类项，位置项与内容项耦合，
    模型难以学到纯粹的相对位置规律。

5.3 旋转位置编码（RoPE）的优势

  1. 相对位置性质是数学恒等式：⟨RoPE(q,m),RoPE(k,n)⟩=q⊤R(n−m) k\langle \text{RoPE}(q,m), \text{RoPE}(k,n) \rangle = q^\top R(n-m)\,k⟨RoPE(q,m),RoPE(k,n)⟩=q⊤R(n−m)k
    严格只依赖 m−nm-nm−n（本文 2.1 节推导、fig_rope_relative 数值验证），
    不需要模型额外学习，归纳偏置直接内建于注意力分数。
  2. 每层都注入新鲜的位置信号：q/k 在每一层注意力前都重新旋转，
    位置信息不会像加法式那样随深度稀释。
  3. 远程衰减的归纳偏置：RoPE 论文证明了在 θi=10000−2i/d\theta_i = 10000^{-2i/d}θi​=10000−2i/d 下，
    内积随相对距离整体衰减（本文 fig_rope_relative 中的振荡衰减形态），
    天然符合"近邻 token 更相关"的语言先验。
  4. 位置与内容解耦：旋转是保模长的正交变换，只改变 q/k 的方向，
    位置作用在注意力分数层面而非表示层面；value 完全不受位置污染，
    语义表示的容量不被位置占用。
  5. 与线性注意力兼容：旋转是乘性变换，满足结合律，
    在核化（线性）注意力中仍可分解出相对位置项；加法式编码则做不到。
  6. 易于扩展到多维位置：分轴旋转即得 2D/3D RoPE（本文第 4 节），
    天然适配图像、视频、3D 体素；正余弦编码扩展到多维需要手工拼接各轴编码，
    且得不到严格的相对位置性质。
  7. 长度外推有成熟的补救工具链：位置插值（Position Interpolation）、
    NTK-aware 缩放、YaRN 等方法只需调整频率或位置缩放系数即可外推数倍上下文，
    无需改架构、无需重训（或仅需少量微调）。
  8. 工程生态成熟：预计算 cos/sin 后只是逐元素乘加，开销极小；
    FlashAttention 等高效内核已原生支持，LLaMA/Qwen 等开源权重可直接复用。

5.4 旋转位置编码（RoPE）的劣势

  1. 直接外推依然会失效：训练长度之外，高频分组会转到模型从未见过的角度，
    注意力分数分布失真。RoPE 的外推优势体现在"有成熟的修正手段"
    （PI / NTK / YaRN / 调大 base），而不是"裸跑就能外推"。
  2. 实现细节多、易踩坑：half 与 interleaved 两种配对约定（本文 2.1 节）
    只差一个维度排列，错误混用不会报错但结果全错；迁移开源权重时必须核对约定，
    cos/sin 缓存的 dtype、设备一致性也需要小心处理。
  3. 频率基数 base 成为新的超参数：长上下文模型需要把 base 从 10410^4104
    一路调到 105∼10610^5 \sim 10^6105∼106（如 LLaMA-2/3），具体取值依赖经验与消融实验。
  4. 无法直接表达绝对位置：内积抹掉了绝对位置信息。对"位置本身就是语义"
    的任务（如坐标回归、依赖绝对网格位置的生成），RoPE 不如加法式编码直接，
    通常需要额外补一路绝对位置嵌入。
  5. 位置信息只存在于注意力路径：FFN、归一化等路径感知不到位置。
    这一般是无害甚至有益的解耦，但某些架构设计（如无注意力的层间混合）
    需要另行考虑。
  6. 超长上下文下缓存与精度问题：cos/sin 缓存随 max_seq_len 线性增长
    （占用很小，百万长度级才显著）；极低频分组在超长序列上角度变化过慢，
    位置区分度下降，这也是 NTK/YaRN 类方法要解决的问题。

5.5 实践建议：如何选择

场景 推荐 理由
现代 LLM（预训练 / 微调） RoPE 严格相对位置 + 逐层注入 + 外推工具链，事实标准
文生视频 / 多帧生成 3D RoPE 分轴编码 (t, h, w)，CogVideoX / HunyuanVideo 同款
复现原始 Transformer、教学 正余弦 PE 最简单、无需改动注意力，便于聚焦原理
需要显式绝对位置（坐标回归、ViT 式 2D 网格） 加法式（可学习或正余弦） RoPE 的相对化反而抹掉了任务需要的绝对信息
极致长度外推（训练 4K 推理 1M） RoPE + YaRN/NTK，或考虑 ALiBi 二者均有成熟方案，正余弦 PE 直接出局

一句话总结：正余弦 PE 赢在简单与可解释，输在位置信号弱、间接、不可外推；
RoPE 赢在把相对位置变成注意力的内建性质且生态成熟，
代价是实现约定繁琐、外推仍需借助修正技巧——这也是它成为现代大模型标配的原因。
